## ✨ Features That Win Freelance Contracts

### 📦 Village & Rural Doorstep Logistics (155,000+ PIN Codes)
- **India Village & Global Rural Coverage**: Doorstep delivery engine covering 155,000+ India Post PIN codes, Gram Panchayats, Tehsils, and remote international postal routes.
- **Delivery Time Guarantee**: Live estimated delivery dates displayed in both the Hero Arena, 1-Click Express modal, and Checkout.

### 💳 UPI & Global Multi-Currency Payments
- **Smart UPI Integration**: Instant payments via Google Pay, PhonePe, Paytm, and dynamic BHIM QR Code generator with 1-tap copy UPI ID.
- **Global Currency Engine**: Real-time auto-conversion between **₹ INR, $ USD, € EUR, and £ GBP** according to customer location.

### ⚡ 1-Click Express Buy (Buyer Friendly)
- Bypass the cart completely with a streamlined 1-tap purchase flow.
- Pre-filled village/city delivery addresses, instant payment mode selector, and animated order receipt generation.

### 🏪 Seller Central Studio (Seller Friendly)
- **Split-Screen Live Buyer's View**: Sellers see their product listing render in real-time as buyers will see it before publishing.
- **6 One-Click AI Templates**: Pre-fill listings for Handloom Silk Sarees, Terracotta Pottery, Leather Jackets, and more.
- **Drag-and-Drop Image Uploader**: Real-time image file preview with automated pricing, category, and inventory controls.

### 👔 Dual-Audience Collections (Men & Women)
- Dedicated Men's & Women's quick category filters with real-time counters.
- Special curated sections for **UdaanMart Karigar Handmade & Rural Artisans** to empower village artisans.

## ⚡ How to Run Locally

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/abhishektripathi9/Amazon-clone-.git
   cd Amazon-clone-
   ```
2. **Start with Node.js**:
   ```bash
   npm start
   ```
   Open `http://localhost:3000` in your browser.

3. **Or Open Directly**:
   Double-click `index.html` in your file explorer to open it in any browser with zero build dependencies!
