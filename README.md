## 🌟 Key Highlights & Engineering Features

- **White & Emerald Technical Aesthetic**: Minimalist, high-contrast engineering layout with sharp monospace accents, subtle grid lines, and glowing emerald highlights.
- **Three.js 3D Spatial Canvas**: Interactive geometric point-cloud mesh with mouse tracking, parallax depth, and smooth 60 FPS animation loop.
- **8-Project Auto-Sliding Carousel**: Smooth 1-by-1 horizontal card sliding with exact 3-second gap, hover-to-pause detection, touch swipe, and synchronized navigation dots.
- **1-Click Direct Action Buttons**: Every project card exposes persistent, touch-friendly action buttons (`🚀 Live Demo`, `👁️ Details`, `💻 Code`) working seamlessly on mobile phones and desktop monitors.
- **100% Confidential Communication Channel**: Visitor inquiry system with zero client-side message leak; public message feeds are completely hidden from non-authenticated visitors, protected by an encrypted Developer Portal PIN (`1808`).
- **Responsive Full-Fill Architecture**: Adaptive viewport scaling ensuring full-width and full-height usability across mobile screens (360px+) and ultrawide 4K monitors.

## 💻 Local Development & Execution

```bash
# Clone the repository
git clone https://github.com/abhishektripathi9/Abhishek_Portfolio.git
cd Abhishek_Portfolio

# Option 1: Using Node.js
npm install
npm start

# Option 2: Using Python built-in server
python -m http.server 3000
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

## 🌐 Deploy to Render

This repository is pre-configured with `render.yaml` for 1-click zero-configuration deployment:

1. Push your repository to GitHub.
2. Log in to [Render Dashboard](https://dashboard.render.com).
3. Click **New +** -> **Static Site** (or **Blueprint**).
4. Connect this repository and set the publish directory to `.`.
5. Render deploys globally across edge CDN nodes with automated HTTPS.
